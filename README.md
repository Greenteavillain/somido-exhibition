# 소미도 · 기억에서 책으로 — 판 6 (벽 재료로 교체, 2026-10-19)

`exhibition-all4/`(전부 펼침 · 누르면 모임)를 복사해 **내용을 벽(가운데 벽 출력물)의 재료로 바꾸고, 카드 모양을 벽 출력물과 같게** 한 판. 전시장 아이맥 + GitHub Pages용.
작가(10-19): "그냥 기존 exhibition4에서 디자인 바꾸고 내용들 바꾸는 방향으로 가자. 내용은 이미 바꿨을 것 같으니 교체" → 범위 "전부 다. 벽에 있는 것 스타일로 전부", 디자인 "벽 출력물과 같은 모양". all4·all5는 비교용으로 그대로.

- **공개 주소: https://greenteavillain.github.io/somido-exhibition/** (GitHub Pages, 레포 Greenteavillain/somido-exhibition = 이 폴더, 2026-10-19 작가가 push). 고친 뒤엔 이 폴더에서 `git add -A && git commit && git push`.
- 열기(개발): 서버(`exhibition/server.py --port 8767`)를 켠 채 http://127.0.0.1:8767/exhibition-all6/ — 또는 폴더를 그대로 정적 호스팅(서버 API 안 씀).
- 만들기: `python3 build_all6.py` → `data/bundle.js`. 금지어(실명·지명)가 남으면 멈춤. `--dev`는 화면 확인용(남은 채로 씀, 올리면 안 됨).

## 내용(build_all6.py)
- 쪽 216장(간지포함2 PDF 재단본, all4 10-18 교체분)은 그대로. **화면 쪽 번호 = 인쇄 쪽**(`data/final_page_map.json`; all4는 PDF 순번이라 벽의 '3쪽'이 '1쪽'으로 보였음).
- 컷 상자(`site/data/site.json`의 cuts, 오타수정본 쪽 기준 비율) → 그대로 얹음. `tools/pagemap.py`로 216쪽 모두 맞춰 봤더니 최종 쪽 그림 = 오타수정본 쪽의 정확히 ½(배율 .5, 어긋남 0, NCC 1.0). 검사 그림 `tools/_pagemap_check.jpg`.
- 구술: 녹취 기록 21개·옛 구술 장면 37개는 **버리고**, 벽 말풍선 36개(자르고 가린 글)를 기록으로, 벽에서 정한 컷에 장면을 만듦.
- 일기 72장: 기록은 그대로(손글씨 SVG), 벽의 형광펜 자리를 `marks`(SVG 비율 상자)로 붙임. 공개 파일엔 **일기 본문 글을 안 실음**(SVG에만 작가가 가린 조각이 반영돼 있음) — 일기 링크의 발췌 글도 지움. 벽에서 정한 컷/쪽에 장면을 더함(이미 같은 쪽에 이어진 것은 안 더함, 55개 추가).
- 포스트잇 42장: 실 매듭 것 36은 실 선 위 문구(`B.threads[].nodes[].note`), 따로 붙이는 것 6은 '작업 메모'(sourceType `postit`) 기록으로 컷에 장면.
- 실 2개(요리 22·사람 16)·짝 24 → `B.threads`·`B.pairs`.
- 나머지 기록(Floe 메모·대화·구성안·결정·초안 — 장면에 쓰이는 것만 110여 개)은 그대로 두되 실명·지명·§4를 가림: `data/scrub_fixes.json`(Workflow all6-scrub-screen → `tools/scrub_from_workflow.py`) + `site-data/_scrub.json` 치환표·금지어. 안 쓰이는 Floe 500장·경로·메모(locator·notes·transcription)는 공개 파일에서 뺌.

## 10-20 작가 피드백 반영
- **처음 화면**: 벽 전체 맞춤 대신 배율 .65(쪽 폭 156px)로 책 첫 쪽이 왼쪽 위. `renderCanvas`의 START_SCALE.
- **Tab 키 = 전체화면**(Fullscreen API). 브라우저가 막으면 안내 토스트.
- **화살표**: ㄱ자 길찾기(cross-router) 안 씀 → 곧은 선. 가운데→가운데로 향하되 상자 테두리에서 여백 12px 떨어진 곳에서 시작·끝(`clipSeg`). 쪽 단위(올림·쪽 클릭)에서는 쪽 가운데로, 컷 클릭(과정)에서는 그 컷 가운데로. 간격은 벽 90(문구 있으면 문구 폭)·모임 140.
- **카드 전부 말풍선**(일기·포스트잇 빼고), 설명 줄·그림자 없음. 실·매듭·실 포스트잇은 평소 안 보이고 올리거나 눌렀을 때만.
- **같은 컷의 벽 기록은 시간순 사슬**(일기 → 사연·구술 → 포스트잇 → 컷, build_all6.py 7b). 쪽 전체에 붙은 일기들은 안 묶음.
- **3단계**(작가 승인): 기록 6개↑이고 사슬 2개↑인 쪽(16쪽쯤)은 쪽 클릭 = 종류별 모아 보기(일기 위·구술 아래·메모 그 아래·포스트잇 오른쪽, 실 앞뒤 쪽·짝 쪽은 좌우로 당겨 옴, 화살표 없음) → 컷에 올리면 그 컷의 기록만 또렷(`.cut-dim`) → 컷 클릭 = 그 컷의 과정(사슬·화살표, key `q:쪽:컷`). 적은 쪽은 쪽 클릭에 바로 과정. 컷 상자 = `B.cuts`. 확인용 `layer.dataset.focusKey/grouped/pageInfo/hoverDbg/pinDbg`.
- 아직: 작가 확인 전 — AI가 쓴 기록 6개(AI 제안·구성안·대조 메모)를 뺄지, 구술 변화 사슬의 화살표 문구(작가 말로 한 줄씩).
- 10-20 저녁: 컷 올림·클릭은 쪽이 눌려 있는 모든 상태(모아 보기·과정·컷 과정)에서 됨. 실 포스트잇 110px, 선을 따라 양옆까지 자리 찾기, **보일 때 끌어서 옮길 수 있음**(localStorage `somido-all6-notes`, 자동 자리 기준 오프셋; 콘솔 `somidoNotesExport()`). 컷 오른쪽 위 초록 점 없앰. 제목 '소미도 근무일지'(부제 없음), 도움말 간소화. 미리보기 서버 루트(/)는 all6으로 302(옛 배열지도가 먼저 뜨던 것).
- **전시장에선 아무것도 못 바꿈**: 포스트잇 끌기·편집 모드는 만들었다가 뺌(작가 10-20 "누가 망가뜨리면 그대로 유지된다는거네? 그런 여지를 남기지 마셈 / 나한테 일을 떠넘기지마"). E/O 편집 단축키 꺼짐. 포스트잇 자리는 자동 배치가 책임짐 — 선을 따라 × 양옆 3칸 → 선 가운데 둘레 나선(반지름 900까지), 쪽·카드·다른 포스트잇을 절대 안 덮음(검사: 37장 겹침 0). 모일 때 옮겨 오는 포스트잇도 모인 쪽·카드를 피해 같은 방식으로.
